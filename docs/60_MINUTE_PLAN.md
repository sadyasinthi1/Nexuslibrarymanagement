**Sole team member: Sadya Sinthi.** Keep scope limited to one `Book` object and register/login. No React is necessary unless your instructor separately requires it.

| Time | Your job |
|---|---|
| 0-10 min | Install/start MongoDB (Docker if installed); copy `.env.example` to `.env`; customize JWT secret. |
| 10-20 min | Run `npm install`, `npm start`, open `http://localhost:3000`. |
| 20-35 min | Register/login and add, read, edit, delete a book. Take actual screenshots. |
| 35-45 min | Import Postman collection, test login, CRUD, 401/no-token. |
| 45-55 min | Add your student ID, actual photo and signature; set up real GitHub and Trello/Jira. |
| 55-60 min | Start recording your 5-10-minute demo; assemble submission links and artifacts. |

**Realistic note:** 60 minutes is a target for an existing environment, not a promise. Installation, troubleshooting, full verification, a 5-10 minute video, and project submission can take longer.
